# SnapStudy AI — Snap-to-Study Flashcard App

Snap a picture of a textbook page or messy handwritten notes. Gemini 3.8 Flash extracts core concepts and generates a deck of 20 digital flashcards with 100% verifiable source citations.

---

## 🚀 How to Run

### 1. Web Prototype & AI Camera (Vite + Express + Gemini)
To run the full web application on your local machine:
```bash
npm install
npm run dev
```
Open **http://localhost:3000** in your browser.

---

### 2. React Native (Expo) Mobile App in Antigravity IDE / VS Code
To run the native mobile app with Expo Camera and 3D Reanimated card flip on your phone or emulator:
```bash
cd mobile
npm install
npx expo start
```
*Or from the root directory:*
```bash
npm run mobile
```
Scan the QR code with **Expo Go** on iOS/Android or press `a` for Android Emulator / `i` for iOS Simulator.
