# SnapStudy AI — React Native (Expo) Mobile App

This folder contains the complete, native mobile version of **SnapStudy AI** built with Expo SDK, `expo-camera`, and `react-native-reanimated` 3D card flips.

## Quick Start in Antigravity IDE or VS Code

### 1. Open the Mobile Project
In your terminal, navigate into this `mobile` folder:
```bash
cd mobile
```

### 2. Install Mobile Dependencies
```bash
npm install
```

### 3. Start Expo
```bash
npx expo start
```

- Press `a` to open in Android Emulator
- Press `i` to open in iOS Simulator
- Scan the QR code using the **Expo Go** app on your physical phone (iPhone or Android) to test the live camera and flashcard flip gestures on your physical device!
